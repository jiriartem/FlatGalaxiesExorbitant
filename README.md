# FlatGalaxiesExorbitant

Bienvenido al glorioso y ligeramente no beligerante universo no explosivo de `FlatGalaxiesExorbitant`
— el único proyecto capaz de doblar galaxias y sentido común con igual desparpajo.

¿Qué es esto?

- Una colección de código que, en teoría, hace cosas relacionadas con galaxias vistas por terraplanistas. En la práctica, es un laboratorio de ideas absurdas 
y números extravagantes. En la práctica: sirve para impresionar a tus colegas y confundir a tu gato, más para lo segundo.

Cómo usar (versión para humanos con sueño):

1. Clona el repositorio. No clones el espaciotiempo, eso es ilegal.
2. Abre el proyecto en tu IDE favorito (para .net, próximamente para Eclipse versión eclipse  bujero negro).
3. Ejecuta. Observa. Pregunta a la consola por respuestas filosóficas y un guión de la vida de bryan pero para alguien coetaneo con Newton o Einstein.
